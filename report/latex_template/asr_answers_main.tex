\subsection{Mandatory ASR Task Questions}

\noindent\textbf{Task 1 (Q1): RoPE memory traffic.}
Rotating the query and key tensors requires
$2(1500)(20)(16)(4)(4)=15.36$ MB of FP32 traffic.
The measured 499.7 GB/s is approximately 81\%
of the stated 616 GB/s peak bandwidth.

\noindent\textbf{Task 2 (Q2): Stable softmax.}
Direct $\exp(100)$ overflows FP32.
Subtracting $m=\max_j x_j$ preserves softmax
because the common exponential factor cancels,
while making every exponent argument non-positive.

\noindent\textbf{Task 3 (Q3): Fused GELU.}
Fusing GELU into GEMM avoids
$2(1500)(5120)(4)=61.44$ MB of extra
global-memory traffic and a separate kernel launch.

\noindent\textbf{Task 4 (Q1): Attention storage.}
A full FP32 attention-score matrix occupies
$20(1500)^2(4)=180$ MB (171.7 MiB).
The tiled kernel uses approximately 17.1 KiB
of dynamic shared memory per block instead of
materialising the full score matrix.
